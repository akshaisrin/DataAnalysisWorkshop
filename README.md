# DataAnalysisWorkshop

**Instructions:**

(1) Download Python and an IDE using this guide: https://docs.google.com/document/d/1S99svy6hmXwYSNPWwfaF8AqbXRe0HFVJbClvdO-DevU/edit?usp=sharing

(2) Then, either clone the repository and open in VSCode (tech team should know how to do this), or just download the zip file, extract, and open the folder in VSCode

(3) Once you open the folder, open up a terminal and type in: pip install -r requirements.txt. The necessary libraries should start to install

(4) Now you're ready to run the program

(5) Go to main.py and hit the run button to the top right

(6) This will take a few seconds to start up, but a graph should appear on your screen

(7) You're done! You should have a fully functional regression program using the TCA mock data!
